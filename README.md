# AtomQuest LiveAssist

## Real-Time Video Support Platform

AtomQuest LiveAssist is a browser-based customer support platform that enables support agents and customers to communicate through real-time video, audio, and chat. The solution uses a self-hosted media server architecture to ensure that audio and video traffic is routed through infrastructure controlled by the organization.

---

## Features

### Core Features

* Agent login and session management
* Customer join via invite link/token
* Real-time audio and video communication
* Self-hosted LiveKit media server
* Real-time in-call chat
* Session tracking and participant presence
* Session history and event logging
* Role-based access control
* Session termination and cleanup

### Bonus Features

* File sharing during support sessions
* Call recording MVP
* Reconnect grace window handling
* Admin dashboard
* Operational metrics endpoint

## Setup Instructions

### 1. Clone Repository

```bash
git clone https://github.com/siddarth2304/AtomQuest-LiveAssist.git
cd AtomQuest-LiveAssist
```

### 2. Configure Environment

```bash
cp .env.example .env
```

### 3. Start Services

```bash
docker compose up -d
```

### 4. Run Database Migration

```bash
npx prisma migrate dev --name init
```

### 5. Seed Demo Data

```bash
npm run prisma:seed
```

### 6. Start Application

```bash
npm run dev
```

### 7. Open Application

```text
http://localhost:3000
```

## Demo Flow

1. Agent logs into the platform
2. Agent creates a support session
3. System generates an invite link
4. Customer joins using the invite link
5. Both participants enter the video session
6. Chat messages can be exchanged
7. Files can be shared
8. Agent may start/stop recording
9. Session can be ended by the agent
10. Session history becomes available in dashboard

## Known Limitations

* Recording functionality is implemented as an MVP using browser MediaRecorder.
* Local file storage is used for demonstration purposes.
* Production deployment should use secure object storage.
* Scalability optimizations are outside the scope of the hackathon prototype.

---

## Why This Solution?

* No third-party hosted video APIs used.
* Audio and video are routed through a self-hosted LiveKit media server.
* Role-based access control ensures security.
* Supports real-world customer support workflows.
* Modular architecture allows future scaling and enhancements.
